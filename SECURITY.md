# Security Policy

## Scope

Lift Louisiana is a static GitHub Pages showcase. It has no server-side runtime, account system, visitor-data collection, or paid-service dependency.

## Safe use

- Do not add credentials, private personal information, or confidential partner data to public HTML, assets, or repository history.
- Review external destinations, imagery, and social links before publishing changes.
- Confirm permission to use logos, photographs, and other third-party material.
- Review any future forms, analytics, embeds, or JavaScript integrations for data collection and third-party disclosure before enabling them.
- GitHub Pages is public hosting; content in the published site and public repository should be treated as public.

## Reporting

Report suspected vulnerabilities privately through GitHub's private vulnerability reporting feature when available. Do not include personal data or secrets in public issues.
